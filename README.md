# QuickGamma

Windows 10 / 11（x64）で、モニターごとのガンマをタスクトレイから調整するツールです。配布物は単体の `QuickGamma.exe` です。

## 使い方

1. [Releases](https://github.com/azumew/QuickGamma/releases) の対象バージョンから `QuickGamma.exe` を保存して起動します。旧版が常駐している場合は、先にトレイメニューから終了します。
2. モニターを選び、スライダーまたは数値欄で **0.25 ～ 4.00** の値を指定します。大きいほど中間調が明るくなります。**1.00** は、そのモニターを最初に変更する直前の色補正です。
3. **OK** で現在の設定を保持してトレイに格納します。**キャンセル** または右上の **×** で、画面を開いた時点の設定に戻します。最小化ボタンではタスクバーに格納します。
4. トレイのアイコンをクリックすると再調整できます。右クリックして **終了して元に戻す** を選ぶと補正を解除します。

**全画面を 1.00 に戻す** で全モニターの調整を解除できます。**ショートカットを作成** で現在の設定をデスクトップに保存できます。ショートカットは作成時のモニター番号を使用するため、接続順を変更した場合は再作成してください。

## コマンドライン

```powershell
# すべてのモニターに適用
.\QuickGamma.exe -g 1.20

# 1 番目と 2 番目に個別の値を適用
.\QuickGamma.exe -m 1 -g 1.30 -m 2 -g 0.90
```

旧版の `/m` と `/g` 形式にも対応します。起動済みなら常駐中の画面に要求を渡します。未起動ならトレイに常駐して復元を担当します。

## 強制終了からの復元

初めてモニターを変更する直前に、RGB 各 256 点の補正テーブルを読み取り、画面識別子とともに `%LOCALAPPDATA%\QuickGamma\recovery-<セッション番号>` へ保存します。保存に失敗した画面への変更は中止します。

同じ exe が復元用の子プロセスとして動作します。画面側のプロセスが強制終了されると、子プロセスはパイプの切断を検知し、保存した補正の復元を試みます。両プロセスを同時に終了した場合は、同じ Windows セッションでの次回起動時に再試行します。対象画面を取り外した場合は記録を保持します。再接続した状態で QuickGamma を起動してください。

書き込み後は補正を読み戻し、ドライバーの丸めを考慮して照合します。HDR、夜間モード、他の色調整ソフトとの併用時の結果は環境に依存します。[Windows のガンマ API の制約](https://learn.microsoft.com/windows/win32/api/wingdi/nf-wingdi-setdevicegammaramp)

## 開発と配布

Rust の安定版（x64 MSVC、1.88 以降）、Visual Studio の C++ デスクトップ開発ツール、Windows SDK を使います。**x64 Native Tools Command Prompt** で次を実行してください。

```cmd
cargo test --locked
cargo build --release --locked
```

実行ファイルは `target\release\QuickGamma.exe` に生成されます。アイコンは 16 ～ 256 px の 7 サイズを埋め込んでいます。ショートカット作成には Windows 標準の Windows PowerShell を使います。

GitHub Actions はプルリクエスト、main への push、手動実行で整形・テスト・ビルドを行います。生成物は実行結果の Artifacts から取得できます。`v` で始まるタグを新しく作成し、main の更新後にタグだけを push すると（例 `git push origin v0.2.1`）、同じ検証を通った exe をそのタグの GitHub Release に添付します。
