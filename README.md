# QuickGamma

ゲームの暗い場面だけ、もう少し見やすくしたい。QuickGamma は、Windows のタスクトレイからモニターごとのガンマを調整できる軽量ツールです。ガンマを上げると、影に近いグレーや中間の色が明るく見えます。

**[Windows x64 版をダウンロード](https://github.com/azumew/QuickGamma/releases/latest/download/QuickGamma.exe)** · [リリース履歴](https://github.com/azumew/QuickGamma/releases)

Windows 10 / 11（x64）対応。インストールは不要です。好きなフォルダーに `QuickGamma.exe` を保存して起動してください。

## こんなときに

- **明るさ設定がないゲームで。** 暗い場面を表示したままスライダーを動かし、陰影が見やすいところを探せます。
- **FPSを遊ぶモニターだけ調整したいときに。** ゲーム画面の中間調を持ち上げ、隣のモニターで開いているチャットや攻略情報は普段の色で読めます。
- **ゲームと普段使いを切り替えたいときに。** 気に入った調整をデスクトップのショートカットに保存しておけば、次回はダブルクリックで同じ設定を呼び出せます。

## 最初の調整

1. ゲームを映すモニターを選び、ガンマを **1.00 → 1.10** など少しずつ動かします。数値の直接入力もでき、変更はその場で画面に反映されます。
2. 気に入ったら **OK** を押します。設定を保ったままトレイに常駐します。試す前の状態に戻したいときは **キャンセル** または右上の **×** を押します。
3. 遊び終えたら、トレイのアイコンを右クリックして **終了して元に戻す** を選びます。常駐を続ける場合は、調整画面の **全画面を 1.00 に戻す** が使えます。

設定範囲は **0.25 ～ 4.00** です。**1.00** は、そのモニターで最初の調整を行う直前の色補正を表します。QuickGamma はこの補正を記録し、操作画面のプロセスが強制終了された場合も、別プロセスから復元を試みます。

## ゲーム用の設定を保存する

モニターごとに値を合わせて **ショートカットを作成** を押すと、全モニターの現在値を含むショートカットがデスクトップにできます。「夜のマップ用」など、分かりやすい名前に変更して使えます。ショートカットは exe の保存場所とモニター番号を使うため、exe の移動や画面構成の変更後は作り直してください。

同じ操作を PowerShell からも実行できます。モニター番号は調整画面の表示に対応します。

```powershell
# モニター2だけにゲーム用の補正を適用
.\QuickGamma.exe -m 2 -g 1.20

# 全モニターを元の補正に戻す
.\QuickGamma.exe -g 1.00
```

## ゲームで変化が見えないとき

補正は選んだモニター全体にかかります。まずデスクトップ上で中間色の変化が見えるか確認してください。デスクトップでは効いても、ゲームが独自の色設定を適用する場合があります。HDR 有効時の動作は Windows のガンマ API で定義されていません。ドライバーが受け付ける補正範囲にも差があります。[Microsoft のガンマ API 解説](https://learn.microsoft.com/windows/win32/api/wingdi/nf-wingdi-setdevicegammaramp)
